The shell is a prompt where you type CQL and shell commands and see the results straight away. It works like `cqlsh`, with a history that survives restarts and output that fits your terminal.

<Tabs>
  <TabItem label="Web UI">
    The web UI has no prompt. Run statements from the query editor instead, and set consistency, page size, and the output you want in its toolbar. See [Browse your schema](/helenus/docs/browse-your-schema/) to explore tables first.
  </TabItem>
  <TabItem label="Shell">
    ## Start the shell

    ```bash
    helenus --profile local
    ```

    The prompt shows the current keyspace:

    ```
    helenus:payments>
    ```

    ## Run a statement

    1. Type the statement and end it with a semicolon.
    2. Press Enter. If the statement is not finished, the prompt changes to `...>` and waits for the rest.
    3. Read the rows. A footer such as `(3 rows)` shows how many came back.

    ```
    helenus:payments> SELECT merchant_id, name
               ...>   FROM merchants LIMIT 2;
    ```

    Shell commands such as `USE`, `CONSISTENCY`, and `PAGING` do not need a semicolon. Everything is case-insensitive.

    ## Switch keyspace

    `USE payments` changes the keyspace and the prompt. Statements that name no keyspace run in it. If the keyspace does not exist, the shell says so and keeps the current one.

    ## Set consistency

    ```
    CONSISTENCY QUORUM
    SERIAL CONSISTENCY LOCAL_SERIAL
    ```

    Type `CONSISTENCY` on its own to see the current level. The setting lasts until you leave the shell. To start with a different level, use `--consistency` or the profile's `consistency` key.

    ## Choose how rows look

    | Command | Result |
    |---|---|
    | `FORMAT table` | A box-drawn grid, fitted to the width of your terminal. Long values end in `…`. Partition key headers are bold and clustering key headers are underlined. |
    | `FORMAT expanded` or `EXPAND ON` | One block per row, headed `@ Row 1`, with one `column | value` line per column. Good for wide rows. |
    | `FORMAT raw` | Tab-separated values with the column names first. Nulls are empty. |
    | `EXPAND OFF` | Back to the table format. |

    ## Page through results

    The shell fetches 100 rows at a time. After each page it shows `--More--`. Press Enter for the next page, or type `q` and press Enter to stop.

    - `PAGING 50` sets the page size.
    - `PAGING OFF` fetches everything without stopping.
    - `PAGING ON` turns paging back on at 100 rows.

    Only the page on screen is read from the cluster, so stopping early does not download the rest.

    ## Warnings and filtering

    Warnings from Cassandra, such as tombstone or batch size warnings, print below the result. If a query needs filtering, the shell shows the server's message and a hint. Add `ALLOW FILTERING` to the statement and run it again if you accept the cost of a wider scan.

    ## Cancel and exit

    - **Ctrl-C** while you are typing drops the statement. While a query is running, it cancels the query.
    - **Ctrl-D** on an empty line leaves the shell. So do `EXIT` and `QUIT`.

    ## Recall earlier statements

    - Press the up and down arrows to move through your history.
    - Press **Ctrl-R** and type part of a statement to search backwards.
    - A statement you typed over several lines is saved as one entry.
    - Statements that contain `PASSWORD`, such as `CREATE ROLE … WITH PASSWORD`, are never saved.

    The history file is `~/.local/state/helenus/history` unless you set `--history-file` or `paths.history`. `--history-size` limits the number of entries (10,000 by default). `--vi-mode` switches line editing to vi keys.

    ## Switch profiles

    `\profile` shows the current profile. `\profile prod-eu` reconnects using another profile from your config file.

    ## Run a file

    `SOURCE 'scripts/setup.cql'` runs every statement in the file and stops at the first error. To run a file without opening the prompt, see [Run scripts with -f and -e](/helenus/docs/run-scripts-with-f-and-e/).

    For the full list of commands, type `HELP` or open the [Shell command reference](/helenus/docs/shell-command-reference/).

## Settings you can change

Each setting has a flag, an environment variable, and a config key. A flag wins over the environment, the environment over the config file, and the config file over the default.

| Setting | Flag | Config key |
|---|---|---|
| Output format | `-F, --format` | `shell.format` |
| Rows per page | `-g, --paging` | `shell.paging` |
| Hide the startup banner | `-q, --quiet` | `shell.quiet` |
| Print the time each statement took | `-m, --timing` | `shell.timing` |
| vi key bindings | `-v, --vi-mode` | `shell.vi_mode` |
| History size | `-n, --history-size` | `shell.history_size` |
| History file | `-j, --history-file` | `paths.history` |
